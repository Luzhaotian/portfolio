## 3. 主推方向

### 名称：**「静奢工作室」Quiet Atelier**

**一句话**：像一家只接难题的前端工作室官网——空间很贵，字很少，动效很慢，材质只露一次。

**高级感从哪来（执行纪律）**

1. **留白加倍**：区块上下 `clamp(6rem, 14vw, 11rem)`；Hero 允许一半屏幕是空的  
2. **字即品牌**：姓名可到 `clamp(3.5rem, 12vw, 7.5rem)`；副文不超过一行半  
3. **只留一个强调色**，且饱和度压低，从不铺大色块  
4. **去掉卡片容器**：无 border-box 堆叠；用字号、位置、细线表达层级  
5. **动效用「呼吸」**：入场 600–900ms、自定义缓动；禁止弹跳、禁止 glow  
6. **Canvas 当材质，不当特效秀**：全站最多两处  

**一个审美冒险**：Hero 姓名用 **ParticleReveal**——粒子收束成汉字，像金属粉尘落成铭牌；这是唯一「会动的奢侈品」。

**刻意避开的「假高级」**

- 奶油底 `#F4F1EA` + 陶土橙 + 大衬线（AI 高频脸）  
- 黑底荧光绿 / 紫渐变 / 多层光晕  
- 密排报纸栏、处处细线框  
- 到处 Glass / Liquid

## 5. 设计 Token

### 5.1 颜色

| 角色 | Hex | 用法 |
|------|-----|------|
| Gallery | `#F6F7F8` | 主背景（冷白，偏画廊，不是暖奶油） |
| Gallery-mute | `#ECEEF1` | 交替章节浅底 |
| Charcoal | `#14151A` | 主标题、姓名 |
| Stone | `#6B7078` | 正文次级 |
| Hairline | `rgba(20,21,26,0.12)` | 分隔线 |
| Patina | `#8F7355` | **唯一强调**（链接、精选点、粒子收束高亮） |
| Patina-soft | `rgba(143,115,85,0.10)` | 选区、轻悬停底 |
| Night（二期） | Gallery→`#0E0F12`，Charcoal→`#EDEEEF`，Patina 略提亮 | 同一版式的夜色 |

**禁止**：`#14b8a6` teal、紫、霓虹、大面积渐变按钮。

### 5.2 字体

| 角色 | 选型 | 用法 |
|------|------|------|
| Display | **Fraunces**（soft optical，或 `SOFT` 轴） | 姓名、章节大标题；字重 500–600，略负 tracking |
| Body | **Söhne 替代：Outfit** 或继续 **Geist Sans** 但全面降权到 400/500 | 导航、正文；字重宁轻勿粗 |
| Mono | **JetBrains Mono** 或 **Geist Mono**，字号小、字距开 | 仅 role 标签、tech、旁注 |

中文姓名与衬线混排：Display 用于「卢照天」；若衬线中文字形弱，姓名可用 **思源宋体 CN**（`Noto Serif SC`）作 Display，英文副标用 Fraunces——二选一，**全站只保留一套 Display 策略**。

**推荐落地**：Display = `Noto Serif SC`（姓名/中文大标题）+ 英文旁注 `Fraunces`；Body = `Geist Sans`。

### 5.3 空间与形态

- 内容宽：`min(1080px, 92vw)` — 比现在更窄，更贵  
- 正文字号：`17–18px`，行宽约 42–58 字  
- 圆角：全局 ≤ `2px`；多数为 `0`  
- 阴影：**默认零**；悬停最多 `0 1px 0 hairline` 式边，不要 soft shadow 卡片  
- 按钮：优先纯文字 `履历` / `GitHub` + 箭头；若需要实心，用 Charcoal 底 + Gallery 字，高度紧凑，无 pill  

### 5.4 氛围材质

- 全页 noise ≈ **2–3%** opacity  
- Hero 右侧或底部一处 **超大径向柔光**（`Patina` 或冷灰，opacity ≤ 0.07）  
- **无** 工程网格、无 Vanta、无扫描线

## 6. 信息架构（数据不变，节奏变贵）

1. **Hero** — 姓名（Particle）/ 头衔 / 一句 tagline / 两个文字链  
2. **Selected** — 仅 `highlight` 项目；**每个一屏式章节**（大标题 + 短述 + tech 一行）  
3. **Profile** — About 文案 + highlights 改成 **四列极细事实**（数字大、标签小）  
4. **Index** — 其余企业 + 开源：极简目录（名 · 技术 · 链），字重轻  
5. **Capability** — Skills：两栏，左分类名（衬线小标），右标签流  
6. **Writing** — Blog：日期 + 标题，像期刊目录  
7. **Fields** — Experience：定义列表，左领域右说明  
8. **Colophon** — Footer 极简  

原则：**精选占视觉预算；其余全部降级成索引。**

## 8. Canvas UI

| 级 | 组件 | 位置 | 高级用法 |
|----|------|------|----------|
| P0 | **ParticleReveal** | Hero 姓名 | 粒子 → 字形；色贴近 Charcoal/Patina；reduced-motion 静态 |
| P1 | **Glass** | Selected 章节标题区 | 低 refraction、低 frost；像镜面铭牌，不是玩具水滴 |
| 不做 | Decrypt（偏黑客）、全页 Bubble/Liquid、Vanta、每区一特效 | | |

```bash
npx shadcn@latest add @canvas-ui/particle-reveal-react
npx shadcn@latest add @canvas-ui/glass-react
```

→ `components/canvas/`

## 9. 动效（高级感关键）

| 场景 | 规格 |
|------|------|
| 页面入场 | Hero：Particle；其余延迟错落，单元素 700ms，`cubic-bezier(0.22, 1, 0.36, 1)` |
| Hover | 字色 → Patina；下划线从 0→100% width，200–250ms |
| 滚动 | 章节号可 sticky；**禁止**视差多层、禁止滚动劫持 |
| 按压 | 文字链无 scale；实心控件最多 `opacity 0.85` |
| reduced-motion | 全关 Particle/Glass；保留即时可见内容 |

## 12. 成功标准

1. 第一眼：**安静、贵、疏**，不像特效站也不像后台模板  
2. 姓名是首屏绝对主角；无 KPI 墙、无玻璃卡阵  
3. 关 Canvas 仍完整可读  
4. 与旧站截图对比，非设计师也认为是另一个品牌  
5. 对比度达标；动效尊重 reduced-motion
